# 🎬 Movie Recommendation Buddy

Developed a content-based movie recommendation system using the TMDB 5000 dataset to suggest movies based on similarity in genres, cast, crew, and keywords. Applied NLP techniques such as tokenization and CountVectorizer to transform movie metadata into numerical vectors, and used cosine similarity to generate personalized recommendations. Built the project using Python, Pandas, NumPy, and scikit-learn.
